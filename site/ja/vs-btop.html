gander / btop との比較

gander vs btop

どちらも htop のレイアウトを拒みます。ただ、その代わりに何を置くかは意見が分かれます。btop はマシンを描き、gander はプロセスを並べます。

「このマシンは今どんな調子か」が知りたいなら btop を。「どのプロセスがやっているのか」が知りたいなら gander を。その答えをスクリプトで欲しい場合も gander です。

インストール ソース

同じカテゴリに見える別のツール

btop はリソースモニターです。CPU、メモリ、ネットワーク、ディスク、温度をグラフと点字プロットで描き、プロセス一覧はそのうちの 1 ボックス。得意なことは得意で、ダッシュボードが欲しいなら正しい選択です。

gander はプロセス一覧です。htop と同じものに、選択プロセスの詳細を別画面から列へ移した構成です。スクリーンショットが説明のすべてです。

gander の panels — メーターを 1 列に圧縮
gander の htop レイアウト(L)

btop のプラットフォーム対応はその点で広く、NetBSD と OpenBSD 向けにもビルドされます。gander はされません。これらのシステムを主戦場にするなら、選ぶのは btop で、このページは対象外です。

実用面で効いてくるのはスクリプト対応

btop は「画面」です。機械可読なスナップショットを受け取る公式の方法はなく、自動化するには表示をスクレイプするか、/proc を自分で読むしかありません。

gander のバッチモードは、TUI を切った同じバイナリです。

gander --json --limit 10                   # JSON 形式で 1 回出力、上位 10 行
gander --sort PERCENT_MEM --limit 20       # メモリ使用量の上位 20 件
gander -F "python|node" -n 5               # 5 回出力、フィルター付き

毎日使う機能ではありません。でも、「見るだけのツール」と「cron に組み込めるツール」の違いです。

インストール

brew install pandasir/tap/gander     # macOS
cargo install gander-bin             # Rust が入っている任意のプラットフォーム

署名付きの apt / dnf リポジトリと 7 ターゲット分のアーカイブは、インストールの節にあります。

さらに読む

vs htop

gander がキーバインドと列の意味を借りているツール。

vs bottom

クロスプラットフォームのグラフとウィジェット、そして「公式サポート」の範囲。
