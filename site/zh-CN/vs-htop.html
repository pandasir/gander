gander / 与 htop 对比

gander vs htop

同样的进程数据,同样的按键。区别在于选中进程的细节放在哪:就在表格旁边,不用再按一次键。

如果只想要每个发行版都自带的那件工具,用 htop。如果已经记熟了 htop 的按键,又想要检视面板、还不想放弃表格,用 gander。

唯一改变工作方式的差别

htop 回答「现在在跑什么」的方式是把所有进程一次铺开;至于「那个进程在干什么」,它放到另一个界面回答——老版本靠信息面板,新版本靠单独的视图。无论哪种,读细节的时候表格都不见了。

gander 让两者同屏。检视面板是表格旁边的一列,跟着光标走:沿着列表往下移,细节就跟着重读,不用每个进程按一次键。宽终端上,这是顺手干活的空白区域;窄终端上,布局会自行收缩,不会互相重叠。

如果你更想要 htop 的排布,按 L。全宽布局是内置的,选择会被记住。

这张表的大部分以 htop 为基准,gander 刻意沿用它的列语义和按键。gander 超出「htop 加一列」的部分是最后三行:批处理模式、Linux 独有的额外列,以及 htop 没有对应物的检视面板。

切换过去,不用重调设置

htop 把设置存在 htoprc 里。gander 读取这个文件并写成自己的 TOML,你调了多年的列和排序就这样跟过来:

gander --import-htoprc ~/.config/htop/htoprc --save

不带 --save 时,导入是一次试运行,只打印会改什么。你的 htoprc 不会被改动,htop 照常工作,两边可以并排比较。

导入器能处理 htop 从 1 开始计数的列 id,天真的转换正是在这里出错。没有 gander 对应项的设置会被报告,而不是悄悄丢掉。

有差别的按键

htop 功能栏里的键都留在 htop 放它们的地方。下面这些不一样:

Ihtop 用它反转排序。gander 用它切换选中表头 meter 的显示模式;改排序用 F6 / < >。
L在 panels 和 htop 布局之间切换。htop 没有这个键。
+ / -加快或放慢采样。
Shift+Left / Shift+Right移动表头 meter 光标。

完整按键表(含批处理模式参数)在 docs/KEYS.md。

安装

brew install pandasir/tap/gander     # macOS
cargo install gander-bin             # 任何有 Rust 的平台

Debian、Ubuntu、Fedora 和 RHEL 的 Linux 包在签名软件源上;每个 Release 附带 macOS(Apple Silicon 和 Intel)、Linux(x86_64 和 arm64)和 FreeBSD 的压缩包。见所有安装方式。
