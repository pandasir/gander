gander / 在 FreeBSD 上

FreeBSD 上的进程查看器

新的终端进程查看器到了 FreeBSD 就变得稀少——不是数据难拿,而是没几个项目在那里测试。

htop 支持 FreeBSD 已经多年,gander 有专门的 sysctl/libkvm 后端,在 CI 里的真实 FreeBSD 内核上测试。如果你在 FreeBSD 上挑新工具,平台支持那一行往往就是全部决定。

gander 在 FreeBSD 上读什么

后端用两个接口。sysctl 提供进程表和系统数字;libkvm(kvm_getswapinfo、devstat_getdevs)补上 sysctl 不暴露的部分。

数字来源
进程列表sysctl(KERN_PROC_PROC) → kinfo_proc[]
CPU 时间、启动时间ki_runtime(微秒)、ki_start
常驻与虚拟大小ki_rssize(页)、ki_size(字节)
状态字母ki_stat 加 ki_tdflags/ki_slptime
命令行、环境变量sysctl(KERN_PROC_ARGS)、KERN_PROC_ENV
可执行文件、cwdKERN_PROC_PATHNAME、KERN_PROC_CWD
打开的文件KERN_PROC_FILEDESC
每核 CPUkern.cp_times
内存vm.stats.vm.v_* 配 v_page_count
Swapkvm_getswapinfo(3)
磁盘吞吐devstat_getdevs(3)
网络吞吐sysctl(NET_RT_IFLIST)
CPU 亲和性cpuset_getaffinity / cpuset_setaffinity

上面每一行都在开发期出过一个 bug,而且只有和别的工具对照才抓得到。挑几个值得知道的:

  • ki_runtime 是微秒,而 Linux 和 macOS 上每个 CPU 时间字段都是 tick 计数。拿它除以 HZ 之类的除数,得到的百分比会差四个数量级。
  • ki_rssize 是页,ki_size 是字节。它们看起来是一对,其实不是;忘了页大小,就会把 1.2 GB 的进程报成 300 MB——错得足够合理,能活过评审。
  • ki_stat 不是状态字母。SSLEEP 会按 ki_tdflags & TDF_SINTR 和 ki_slptime 一分为三;按算术映射,新生的进程会显示成 I,被锁住的显示成 X。
  • kvm_getswapinfo 报告的是页。htop 自己的 FreeBSD 后端乘的是 1024 而不是页大小,把 1 GiB 的 swap 文件报成 4 MiB,还标成字节。gander 按 swapinfo(8) 的做法来。
  • hw.physmem 比虚拟机实际管理的内存大,拿它当内存条的总量,内存条就永远差一截满不了——在一台真的内存见底的机器上,这看起来像渲染 bug。

FreeBSD 没有的东西,gander 会明说

和 macOS 同一条规则:只会渲染 - 的列从列清单里移除,meter 留在原处显示 n/a here,配置文件在机器之间挪动仍能加载。

在 FreeBSD 上
PSS / EPSS没有 smaps_rollup;被排除
PSI、zram、zswap、HugePagesmeter 显示 n/a here
容器列jails 不是容器;被排除
GPU 列没有 drm-usage-stats;被排除
延迟统计TASKSTATS 只在 Linux 有;被排除
I/O 优先级(i)没有 ioprio_set;面板会说明
文件锁面板(x)没有锁表;指向 lsof
CPU 亲和性、环境变量、打开的文件受支持
主机级磁盘吞吐受支持,唯一同时有两个数字的平台

jails 是有意思的那个空缺。kinfo_proc.ki_jid 有读到、也拿得到,但没有任何东西渲染它:jail 与内核共享,没有镜像层,除一个小整数外没有别的身份,把它列成 CONTAINER 会是虚假的等价。jid 0 是宿主,也是常见情形,所以那一列会是一排零带几个例外。

它怎么测试

FreeBSD 没有 GitHub 托管的 runner,所以用两种方式检查:每次 push 都把整个 crate 交叉编译到 x86_64-unknown-freebsd;以及在 QEMU 的 FreeBSD 14 虚拟机里完整跑一遍测试。真正要紧的是虚拟机那条任务——实时测试在虚拟机内把 gander 的数字与 ps(1)、sysctl(8)、swapinfo(8) 和 netstat(1) 对照。上面列出的大多数 bug,交叉编译是看不见的。

完整矩阵——包括每个平台上刻意缺失的每一行——在 docs/PORTABILITY.md。

在 FreeBSD 上安装

每个 Release 都有 x86_64-unknown-freebsd 压缩包,旁边带 .sha256 文件:

tar -xzf gander-<version>-x86_64-unknown-freebsd.tar.gz
./gander-<version>-x86_64-unknown-freebsd/gander

有 Rust 工具链的话:

cargo install gander-bin

当前压缩包见 Release,全部安装方式见安装一节。
