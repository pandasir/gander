gander0.6.7

Rust로 작성된 Linux·macOS·FreeBSD용 크로스플랫폼 대화형 프로세스 뷰어입니다.

htop이 읽는 것과 같은 프로세스 데이터를 읽고 htop의 키 바인딩을 그대로 쓰며, 선택한 프로세스의 세부 정보를 목록 옆에 둡니다. htop은 이를 별도 화면에 내보냅니다.

다운로드 GitHub에서 소스 보기 설치

gander가 하는 일

gander는 시스템에서 무엇이 실행 중인지, 비용이 얼마인지 보여 줍니다. Linux, macOS, FreeBSD에서 실행되며 대부분의 htop 키 바인딩을 그대로 쓰므로, 손에 익은 키가 그대로 동작합니다.

상세 정보 패널은 커서를 따라갑니다

행을 선택하면 오른쪽 패널이 채워집니다. 명령줄, 상태, 메모리, 실행 시간, 사용자, 스레드.

샘플링은 렌더링 경로 밖에서

백그라운드 스레드가 샘플링하고 렌더러는 스냅샷을 읽습니다. 시스템이 바쁠 때 — 바로 그때 표를 들여다보고 있을 때 — 표가 버벅이지 않습니다.

htop 설정도 그대로 가져옵니다

--import-htoprc는 기존 htoprc를 읽고, --save는 이를 gander 고유의 TOML로 기록합니다. 다듬어 둔 열 구성과 정렬 순서는 전환 후에도 살아남습니다.

TUI 없이 스크립트에서

--json, -n, --sort, --filter, --limit은 프로세스 행을 출력하고 종료합니다. curses 화면을 긁어 파싱할 필요가 없습니다. 필드와 jq 예제는 배치 모드 페이지에 있습니다.

Linux에서는 볼 수 있는 데이터가 더 많습니다

PSS/EPSS, PSI, zram/zswap, GPU, 지연 통계, 컨테이너 식별 정보를 선택적 열이나 헤더 미터로 추가할 수 있습니다. /proc과 /sys에서 읽습니다.

ncurses 설치가 필요 없습니다

ratatui와 crossterm으로 렌더링합니다. 빌드 전에 설치할 개발 헤더도, 링크할 터미널 라이브러리도 없습니다.

같은 시스템을 보는 세 가지 방법

panels — 기본 전체 크기 이미지 보기 (새 탭)
t — 프로세스 트리 전체 크기 이미지 보기 (새 탭)
L — htop 레이아웃 전체 크기 이미지 보기 (새 탭)

대시(—)는 해당 사항 없음입니다. htop은 정의상 htop의 키 바인딩을 쓰고 htop의 설정을 읽습니다.

매일 쓸 때 차이를 만드는 행은 선택한 프로세스에 관한 행입니다. htop, btop, bottom은 모두 모든 프로세스를 한꺼번에 펼쳐서 “지금 뭐가 돌고 있나”에 답하고, 궁금한 프로세스의 세부 정보는 별도 화면에 있거나 아예 없습니다. gander는 상세 정보 패널을 표 옆에 두므로, 행을 고르는 순간 목록을 떠나지 않고 답을 얻습니다.

도구별 긴 비교는 여기에 있습니다: gander vs htop, gander vs btop, gander vs bottom. 플랫폼별 참고 사항은 macOS 편과 FreeBSD 편을 보세요.

설치

macOS (Homebrew)

brew install pandasir/tap/gander

Rust가 있는 모든 플랫폼

cargo install gander-bin   # 설치되는 명령은 `gander`

Arch Linux

git clone https://github.com/pandasir/gander
cd gander/packaging/aur && makepkg -si

Debian, Ubuntu

curl -fsSL https://pandasir.github.io/gander/gander.gpg \
  | sudo gpg --dearmor -o /usr/share/keyrings/gander.gpg
echo "deb [signed-by=/usr/share/keyrings/gander.gpg] https://pandasir.github.io/gander stable main" \
  | sudo tee /etc/apt/sources.list.d/gander.list
sudo apt update && sudo apt install gander

Fedora, RHEL

sudo rpm --import https://pandasir.github.io/gander/RPM-GPG-KEY-gander
sudo curl -fsSL https://pandasir.github.io/gander/gander.repo \
  -o /etc/yum.repos.d/gander.repo
sudo dnf install gander

미리 빌드된 압축 파일

모든 Release에 macOS(Apple Silicon 및 Intel), Linux(x86_64 및 arm64, glibc와 정적 musl), FreeBSD용 .tar.gz 압축 파일이 포함되며, 각각 .sha256 파일이 함께 제공됩니다. GitHub Release를 참고하세요.

소스에서 빌드

Rust 1.89 이상이 필요합니다.

git clone https://github.com/pandasir/gander
cd gander
cargo install --locked --path crates/bin

사용법

gander                                     # 대화형 TUI
gander --delay 500                         # 500밀리초마다 샘플링
gander -n 5 -d 1000                        # 텍스트 샘플 5회 출력
gander --json --limit 10                   # JSON 샘플 1회 출력
gander --sort PERCENT_MEM --limit 20       # 메모리 사용률 상위 20개
gander -F "python|node"                    # 명령줄로 필터링
gander --import-htoprc ~/.config/htop/htoprc --save

필터 항목은 대소문자를 구분하지 않는 고정 문자열이며 |로 구분합니다. 정규 표현식이 아닙니다. 전체 옵션은 gander --help에서 확인할 수 있습니다.

자주 묻는 질문

gander는 htop을 대신할 수 있나요?

됩니다, 그리고 안 됩니다. 같은 /proc 데이터를 읽고 키도 htop 자리에 있으므로 지금 쓰는 방식이 그대로 통합니다. --import-htoprc로 htop 설정을 그대로 가져올 수도 있습니다. 다만 기본 레이아웃은 의도적으로 htop과 다릅니다. 전체 너비 표에 세부 정보는 별도 화면에 두는 방식이 프로세스 목록을 읽는 유일한 방법은 아니기 때문입니다.

Windows에서 되나요?

안 됩니다. 백엔드는 /proc(Linux), sysctl/Mach/libproc(macOS), sysctl/libkvm(FreeBSD) 세 가지이고 Windows용은 없습니다. Linux 커널 인터페이스에 기대는 열(PSS, PSI, zram, 지연 통계, 컨테이너)도 Linux 전용입니다.

crates.io 패키지 이름이 gander-bin인 이유는?

crates.io의 gander는 무관한, 오래전에 yank된 크레이트이기 때문입니다. 설치되는 명령 이름은 그대로 gander입니다.

ncurses를 쓰지 않는 이유는?

렌더링은 ratatui와 crossterm으로 하므로, 빌드 전에 ncurses 개발 헤더를 설치할 필요가 없습니다.

스크립트에서 쓸 수 있나요?

됩니다. gander --json, -n, --sort, --filter, --limit은 TUI를 띄우지 않고 프로세스마다 한 줄을 출력합니다. 필드 레퍼런스와 jq 예제는 JSON 프로세스 목록 페이지에 있습니다.

gander의 라이선스는 무엇인가요?

GPL-2.0-or-later입니다. gander의 동작, 키 바인딩, 열의 의미는 htop에서 가져왔으므로 라이선스 호환성을 유지하고 출처를 명시해 주세요.
