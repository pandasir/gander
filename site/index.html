gander0.6.7

A cross-platform interactive process viewer for Linux, macOS and FreeBSD, written in Rust.

It reads the same process data htop reads, keeps htop's keybindings, and puts the details of the selected process beside the list; htop puts them on a second screen.

Download Source on GitHub Install

What it does

gander shows what is running on your system and how much it costs. It runs on Linux, macOS and FreeBSD, and it keeps most of htop's keybindings, so the keys you already have in your fingers keep working.

The inspector follows the cursor

Selecting a row fills in the panel on the right: command line, state, memory, runtime, user, threads.

Sampling is off the render path

A background thread samples; the renderer reads a snapshot. The table does not stutter when the machine is busy, which is exactly when you are looking at it.

htop's settings come with you

--import-htoprc reads an existing htoprc, and --save writes it out as gander's own TOML. Your columns and sort order survive the switch.

Scriptable without the TUI

--json, -n, --sort, --filter and --limit print process rows and exit. Nothing to parse out of a curses screen. The fields and jq examples are on the batch mode page.

More to read on Linux

PSS/EPSS, PSI, zram/zswap, GPU, delay accounting and container identity are optional columns or header meters, read from /proc and /sys.

No ncurses to install

Rendered with ratatui and crossterm. There is no development header to install before the build, and no terminal library to link against.

A dash means not applicable — htop has htop's keybindings and reads htop's config by definition.

The row that matters in daily use is the one about the selected process. htop, btop and bottom all answer "what is running" by showing you every process at once, and the details of the one you care about live on a separate screen or nowhere. gander puts the inspector beside the table, so selecting a row answers the question without leaving the list.

Install

macOS (Homebrew)

brew install pandasir/tap/gander

Any platform with Rust

cargo install gander-bin   # the installed command is `gander`

Arch Linux

git clone https://github.com/pandasir/gander
cd gander/packaging/aur && makepkg -si

Debian, Ubuntu

curl -fsSL https://pandasir.github.io/gander/gander.gpg \
  | sudo gpg --dearmor -o /usr/share/keyrings/gander.gpg
echo "deb [signed-by=/usr/share/keyrings/gander.gpg] https://pandasir.github.io/gander stable main" \
  | sudo tee /etc/apt/sources.list.d/gander.list
sudo apt update && sudo apt install gander

Fedora, RHEL

sudo rpm --import https://pandasir.github.io/gander/RPM-GPG-KEY-gander
sudo curl -fsSL https://pandasir.github.io/gander/gander.repo \
  -o /etc/yum.repos.d/gander.repo
sudo dnf install gander

Prebuilt archives

Every release ships .tar.gz archives for macOS (Apple Silicon and Intel), Linux (x86_64 and arm64, glibc and static musl), and FreeBSD, each with a .sha256 file. See GitHub Releases.

From source

Requires Rust 1.89 or newer.

git clone https://github.com/pandasir/gander
cd gander
cargo install --locked --path crates/bin

Use

gander                                     # interactive TUI
gander --delay 500                         # sample every 500 ms
gander -n 5 -d 1000                        # five text samples
gander --json --limit 10                   # one JSON sample
gander --sort PERCENT_MEM --limit 20       # top 20 by memory
gander -F "python|node"                    # filter command lines
gander --import-htoprc ~/.config/htop/htoprc --save

Filter terms are case-insensitive fixed strings separated by |; they are not regular expressions. Run gander --help for all options.

FAQ

Is gander an htop replacement?

Yes and no. It reads the same /proc data and keeps htop's keys, so it drops into the way you already work, and --import-htoprc copies your htop settings over. But the default layout is deliberately not htop's, because a full-width table with the details on a second screen is not the only way to read a process list.

Does gander run on Windows?

No. The three backends are /proc (Linux), sysctl/Mach/libproc (macOS) and sysctl/libkvm (FreeBSD). There is no Windows backend, and the columns that depend on Linux kernel interfaces (PSS, PSI, zram, delay accounting, containers) are Linux only.

Why is the crates.io package called gander-bin?

Because gander on crates.io is an unrelated, long-yanked crate. The installed command is still gander.

Why does gander not use ncurses?

It renders with ratatui and crossterm, so there is no ncurses development header to install before building.

Can gander be used in scripts?

Yes. gander --json, -n, --sort, --filter and --limit run without the TUI and print one row per process. The field reference and jq examples are on the JSON process list page.

What is gander's license?

GPL-2.0-or-later. gander takes its behaviour, keybindings and column semantics from htop, so keep the license compatible and credit it.
